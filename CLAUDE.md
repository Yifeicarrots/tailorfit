@AGENTS.md

## Status

TailorFit is currently a fresh `create-next-app` scaffold (single commit). `app/page.tsx` is still the template landing page and `app/layout.tsx` still has the default "Create Next App" metadata — there is no domain code, data layer, or test setup yet.

## Commands

- `npm run dev` — dev server at http://localhost:3000 (Turbopack)
- `npm run build` — production build; also the type-check gate (there is no separate `tsc` script)
- `npm run start` — serve the production build
- `npm run lint` — ESLint 9 flat config (`eslint-config-next` core-web-vitals + typescript)

No test runner is configured.

## Stack and non-default configuration

- **Next.js 16.4 / React 19.3, App Router only** (`app/` directory, no `src/`). Per AGENTS.md, APIs differ from older Next.js — check `node_modules/next/dist/docs/` (`01-app/`, `03-architecture/`) before using an unfamiliar API.
- **`cacheComponents: true`** in `next.config.ts` enables Cache Components: data fetching is dynamic by default and caching is opt-in via `"use cache"`; uncached dynamic data must sit under a `<Suspense>` boundary. Read the caching docs before adding data fetching.
- **`partialPrefetching: true`** is also enabled in `next.config.ts`.
- **Tailwind CSS v4** is wired through a Turbopack loader rule (`@tailwindcss/turbopack` on `*.css`) rather than PostCSS — there is no `postcss.config` or `tailwind.config`. Theme tokens are defined in `app/globals.css` via `@import "tailwindcss"` and `@theme inline` (CSS variables `--background`/`--foreground`, dark mode via `prefers-color-scheme`).
- Layouts/pages use the generated global route types (e.g. `LayoutProps<"/">` in `app/layout.tsx`) rather than hand-written prop types; these come from `.next/types` generated by `next dev`/`next build`.
- Fonts: Geist / Geist Mono via `next/font/google`, exposed as `--font-geist-sans` / `--font-geist-mono`.
- Path alias `@/*` maps to the repo root.
