# TailorFit

TailorFit helps job seekers tailor their resume to a specific job. You store all your experiences and projects once. For each application, you paste in a job description, and the app uses the Claude API to pick your most relevant experiences and rewrite their bullet points to fit the role, without inventing skills, employers or numbers. You review and approve every change. See the [product requirements](docs/PRD.md).

Built by **Yanni Zhao** and **Yang Zhang** for the P3 Claude Code workflow assignment.

## Running it locally

TailorFit runs on `localhost` only and must not be deployed publicly: there is no real authentication, so a public deployment would let anyone spend the API key.

```bash
npm install                 # npm ci currently fails: package-lock.json is out of sync
cp .env.example .env.local  # then add your ANTHROPIC_API_KEY
npm run dev                 # http://localhost:3000
npm test                    # unit tests (no network, no API key)
```

Pages: `/` (demo sign-in), `/library` (experience library), `/review` (bullet comparison, on fictional sample data until the rewriter's Server Action is connected).
