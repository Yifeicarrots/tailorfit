  - Numbers: any number in the rewrite that isn't in the original is rejected,
    for example 40%, 150, or the 3 in 3-day.

    flagged if it looks like a name. That means it contains +, # or an inner dot
    (C++, Node.js), or it's an acronym (SQL), or it's capitalised anywhere
    except the first word (React, Northwind). Matching ignores case and
    surrounding punctuation, so react in the original allows React in the
    rewrite.
  - It returns { ok: true }, or { ok: false, problems } with one plain sentence
    per problem. Those sentences are ready to send back as the retry feedback.

  fixed:
  - A skill written in lowercase isn't caught, e.g. "using docker".
